Breakpoint observation

First observed failure: During a temporary horizontal flex test in DevTools, the "My Account" navigation label still wrapped at 535px.

Observed width: 540px was the first tested width where all navigation labels fit on one line without wrapping.

Chosen relative-unit breakpoint: 33.75rem

  • 1rem = 16px
  • 540 ÷ 16 = 33.75

JavaScript explanation

The script adds a "js" class to the document, reveals the menu button, and initializes the menu as collapsed. A single function keeps the button's aria-expanded value synchronized with whether the navigation list is hidden. Clicking the Menu button reverses the current state. When Escape is pressed while the menu is open, the script closes the menu and returns keyboard focus to the Menu button.
